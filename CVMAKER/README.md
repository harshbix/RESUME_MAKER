# CV Maker — Premium Resume Builder

Frontend-only React resume builder with smart import, live A4 preview, and high-fidelity PDF export.

## Features
- Smart resume import (PDF/DOCX) with deterministic parsing
- Live A4 preview with ATS-friendly layout
- Design studio for color, typography, layout, and spacing
- Profile photo upload with compression
- High-resolution PDF export

## Development
1. Install dependencies
2. Run the dev server

## Scripts
- `npm run dev`
- `npm run build`
- `npm run preview`
